## Изменение

Существующий бот не защищает webhook, хранит историю на эфемерном диске и может одновременно расходовать квоту нескольких LLM-моделей. Эта версия добавляет PostgreSQL-память и очередь до подтверждения webhook, последовательную обработку пользователя, секрет webhook, меню, безопасный вывод длинных ответов, ограниченные графики, инструменты погоды и опционального поиска.

Обновлены и зафиксированы зависимости. RLS закрывает таблицы от публичного доступа, TLS проверяет сертификат/hostname внешней базы. Включены миграция read-only SQLite backup, проверка базы без записи, документация и план обновления/отката DEPLOYMENT.md.

## Проверки

- 68 tests passed на Python 3.11 с одноразовой настоящей PostgreSQL 16; внешние API подменены.
- 6000 синтетических LLM-вызовов, максимум 2 одновременно, без нагрузки на Telegram/Groq.
- pip-audit: No known vulnerabilities found в установленном окружении после обновления.
- Docker build и проверка ограниченного построения графика.

## Блокеры перед merge/deploy

Черновик до живой интеграционной проверки. Нет Render-доступа, реальных ключей/API-проверки и внешней PostgreSQL. Текущие бесплатные квоты/тарифы не подтверждены; 5000–6000 реальных запросов/сутки не обещаны. Main и существующий Render deploy не изменяются. Перед merge проверить Auto-Deploy, backup, текущий deployed SHA и пройти DEPLOYMENT.md. Не создавать новый Render-сервис и не включать платный тариф.
